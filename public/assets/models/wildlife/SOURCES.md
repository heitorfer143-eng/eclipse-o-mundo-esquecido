# Wildlife models

The ambient wildlife system uses three models from the Gobkit Animal Pack:

- Corgi — https://raw.githubusercontent.com/Ariescar/gobkit-free-assets/main/animal/Corgi.glb
- Red (red panda) — https://raw.githubusercontent.com/Ariescar/gobkit-free-assets/main/animal/Red.glb
- Rhino — https://raw.githubusercontent.com/Ariescar/gobkit-free-assets/main/animal/Rhino.glb

Source catalog: https://github.com/Ariescar/gobkit-free-assets
Integration reference: https://github.com/Ariescar/gobkit-free-assets/blob/main/INTEGRATION.md
License: CC0 1.0 Universal; commercial and personal use permitted, no attribution required.

Models are loaded lazily from the source repository at runtime. They are not duplicated in this repository. If the upstream files become unavailable, the wildlife loader logs the failure and the rest of the game continues normally.
