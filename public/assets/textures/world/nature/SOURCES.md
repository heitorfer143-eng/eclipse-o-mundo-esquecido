# Nature texture assets

Selected from the user-provided Stylized Nature MegaKit [Standard] ZIP, `glTF/` directory:

- `Bark_NormalTree.png` → `bark-tree.webp` (1024 px max, WebP quality 84).
- `Bark_NormalTree_Normal.png` → `bark-tree-normal.webp` (1024 px max, lossless WebP).

The paired bark maps use the procedural trunks' cylindrical UV mapping and are registered only on tree trunks. Atlas/foliage masks were excluded because the game's current terrain/foliage UVs would stretch them incorrectly. The source archive's `License_Standard.txt` identifies the package as CC0 1.0 Universal.
